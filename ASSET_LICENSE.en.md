# Material terms

[简体中文](ASSET_LICENSE.md) · [Project home](README.en.md)

## Permitted use

Artifact images, scanned pages, processed images, thumbnails, archival text, OCR, translations, runtime data and screenshots containing these materials may be used for learning, exchange and noncommercial distribution. Commercial use is prohibited. Material authorization comes from the School of Art and Design, Huainan Normal University (淮南师范学院美术与设计学院).

Retain these terms, existing source information and attribution when redistributing materials. Commercial uses and uses beyond this scope require separate permission from the relevant rights holders.

Original code and engineering documentation use the [MIT license](LICENSE). Third-party software retains its own licenses; see [third-party notices](THIRD_PARTY_NOTICES.en.md).

## Covered files

- `public/assets/ceramics/`: artifact images, thumbnails, archive index and extracted text.
- `src/data/shouzhou_ceramics.json`: descriptions, translations and runtime data.
- `artifacts/`: screenshots containing artifact materials.
- `docs/assets/`: homepage cover and feature screenshots; see the [visual asset notes](docs/assets/README.md).
- Artifact names, information and images referenced in `docs/catalog.json`, inventories and discovery indexes follow the terms of their source materials.

## Sources and content

Original filenames, archive identifiers, associated files and SHA-256 hashes are recorded in the [inventory](docs/ASSET_INVENTORY.en.md) and [machine-readable manifest](docs/asset-rights.json). Numbers in source filenames support file tracing; unknown publication editions and printed page numbers remain unspecified.

Archival text includes OCR and machine-assisted translations. Processed images retain their processing metadata. Consult the scanned archive alongside images and descriptions. To suggest a correction, include the archive ID, file path and a verifiable source.
