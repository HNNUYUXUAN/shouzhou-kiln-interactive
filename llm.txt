# Shouzhou Kiln Interactive Gallery / 寿州窑交互展台

> A React gallery of 78 artifacts, with archive comparison and fullscreen reading. / 包含 78 件文物、档案对照与全屏阅读的 React 展台。

Code and original engineering text: MIT. Artifact materials and documentation visuals: noncommercial learning, exchange and distribution under their linked terms. / 代码与原创工程文字采用 MIT；文物素材与文档图片按所链接条款用于交流学习与非商用分发。
